# День 24 — источники, цитаты и отказ при слабом контексте

В режиме «С RAG» ответ формируется из тезисов, каждый из которых содержит
ссылку на найденный чанк и дословную цитату. Сервер проверяет ID чанка и
совпадение цитаты с **тем фрагментом, который был передан модели**, затем сам
собирает текст ответа и список источников. Некорректный ответ генерируется
повторно один раз; при повторной ошибке пользователь получает сообщение о том,
что подтверждение сформировать не удалось. Если фильтр не оставил ни одного
чанка, генерация ответа не вызывается: ассистент говорит «не знаю» и просит
уточнить вопрос. Если чанки есть, но в них нет ответа, модель также может
вернуть «не знаю» без ссылок.

Старые скрипты сравнения Дней 22 и 23 явно используют прежний формат ответа,
чтобы их контрольные прогоны оставались воспроизводимыми. В обычном чате новый
формат обязателен для каждого содержательного RAG-ответа. При отказе списки
источников и цитат пусты: нерелевантный текст не подтверждает отсутствие ответа.

Вопрос 2 обнаружил, что строгая проверка имени `ThreadPerTaskWebServer`
отбрасывала продолжение того же раздела: имя было в чанке `structure-0007`,
а объяснение потокобезопасности — в `structure-0008`. Фильтр теперь допускает
непосредственно следующий чанк того же раздела при наличии релевантного
именованного чанка. После исправления вопрос 2 получил подтверждённый ответ.

В вопросе 3 ответ верно назвал параллельную отрисовку текста, но не упомянул
последующее ожидание через `Future.get`, записанное в ожидаемом результате.
Это пропуск полноты, хотя приведённая цитата поддерживает сказанное. У
вопроса 8 reranker пропустил несколько чанков, но модель отказалась называть
несуществующий точный размер пула для 64-ядерного сервера. Вопросы 9 и 10
были отсечены поисковым фильтром.

Проверка дословности и наличия источника выполняется кодом; смысловую
поддержку тезисов оценивали вручную. Один прогон не гарантирует такую же
полноту и точность при других вопросах или повторной генерации. Извлечённые
из PDF цитаты иногда сохраняют разрывы слов исходного текстового слоя.

Для повторения после настройки `.env`, установки зависимостей индексации и
наличия официального sample PDF:

```bash

```

Для [36-секундного видео](../artifacts/day24-rag-citations.mp4) из
