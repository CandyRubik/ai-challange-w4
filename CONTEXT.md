# RAG-чат

Отдельная область приложения для диалогов по индексированным материалам и сохранённым договорённостям с пользователем.

## Язык предметной области

**RAG-чат**:
Диалог с собственной историей и памятью задачи, который обращается к базе знаний при каждом вопросе пользователя.

**Память задачи**:
Зафиксированные в одном RAG-чате цель пользователя, ограничения, уточнения и значения терминов. В чате активна одна цель; новый чат начинает с пустой памятью задачи.

**Уточнение**:
Явно сообщённое пользователем изменение цели, ограничения или значения термина. Неясная отсылка сама по себе не меняет память задачи.

**Подтверждённый источник**:
Фрагмент индексированного материала, поддерживающий утверждение о нём, либо сообщение пользователя, поддерживающее запись о договорённости. Ни один из этих видов источника не подтверждает утверждения другого вида.
